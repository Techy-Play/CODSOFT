# CODSOFT PROJECT INTERNSHIP REPOSITORY

## To-Do List Application

A simple and user-friendly To-Do List application developed using Python.  
This project allows users to manage their daily tasks efficiently through a command-line interface.

Users can add new tasks, view existing tasks, mark tasks as completed, and delete tasks easily.  
The application also uses file handling to save tasks permanently, ensuring that tasks remain stored even after closing the program.

This project was developed as part of the CODSOFT Python Programming Internship and helped improve understanding of Python fundamentals such as:

* Lists
* Functions
* Loops
* Conditional statements
* File handling
* User input management
