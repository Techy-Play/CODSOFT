# Python To-Do List Application

A simple command-line based To-Do List application built using Python for the CodSoft Python Programming Internship.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Persistent task storage using text files
- Input validation
- Terminal screen clearing for better user experience

## Technologies Used
- Python
- File Handling
- Exception Handling

## How It Works
- Tasks are stored in a `task.txt` file
- Tasks remain saved even after closing the program
- Users can manage tasks using a menu-driven interface

## How to Run

```bash
python todo.py
```
